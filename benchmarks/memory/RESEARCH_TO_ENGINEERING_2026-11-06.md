# 从论文机制到这轮可验证的工程变更

本轮按用户授权开展真实DeepSeek实验；研究服务于可检验假设，不把其他系统的论文分数归为Memz成绩。原始来源重新核查日期为2026-11-06，未复制第三方代码、运行OpenViking或生成第三方系统排行榜。

| 原始依据与阅读范围 | 对Memz的具体启发 | 本轮实施及验证边界 |
| --- | --- | --- |
| [OpenViking Context Layers](https://github.com/volcengine/OpenViking/blob/739e17f9172b9f595bfe4cc95293ec52d4686120/docs/en/concepts/03-context-layers.md)，固定739e17f，完整概念文档 | 导航表示和正文证据分开，明确内容层级 | 新增显式reader投影，缩小模型视图，同时保留原始来源全文和修订引用；没有生成L0/L1摘要、目录向量索引或移植AGPL代码 |
| [LongMemEval v2](https://arxiv.org/html/2410.10813v2)，摘要、能力定义及附录D | 分开索引/检索/阅读；更新、时间与拒答单独计分；key expansion和time-aware query是不同干预 | 本轮固定批准状态后测阅读，加入历史与拒答题；开发集历史失败触发显式历史补读。自然语言整句召回单独诊断，不用gold修复查询 |
| [MemGPT v2](https://arxiv.org/abs/2310.08560v2)，原始摘要，细节另见前轮研究 | 工作上下文不等于所有持久记忆，应有显式补读路径 | 当前事实与历史修订采用独立接口和分页合同；不声称实现模型自主内存调度、heartbeat或虚拟无限上下文 |
| [A-MEM v11](https://arxiv.org/abs/2502.12110v11)，原始摘要，细节另见前轮研究 | 关键词/标签/链接可以帮助索引和召回 | 暂未实施关联图。后续可把这些内容做成绑定revisionId的可重建索引，不能使模型派生信息变为已批准事实 |

LongMemEval附录D中，用户事实抽取使用Llama 3.1 8B Instruct及人工修改的示例；time-aware query扩展由LLM抽取时间区间；阅读采用Chain-of-Note变体，先提取证据再回答。它们需要独立模型调用和成本。本轮没有复用其抽取器、提示、800-token生成设置或官方评测；使用256-token严格JSON回答及确定性评分。因此这轮是借鉴实验维度的原创合成产品测试，不是LongMemEval复现。

本轮的两个工程假设可以分别被证伪：

1. **视图精简假设**：固定同一approved snapshot，只改变模型输入投影；如果答案/引用变差，就不能用token减少抵消质量回退。开发与留出分开报告。
2. **历史可达性假设**：已有数据库保存旧修订，但只给模型当前事实时无法回答被替代值。新增history→固定版本provenance读取，并对所有问题统一提供同一历史组，避免通过题型或gold选证据。若错误仍存在，应区分检索缺证据与模型读错。

下一轮工程优先级按本轮实际失败排序：

1. **自然语言召回**：为现有字面搜索增加显式规划/混合检索入口。先锁定多项目、别名、代词、长历史及无答案测试集，再比较原问题、关键词规划、词法/向量混合；计入planner/embedding/reranker调用与错项目风险。不得用正确答案构造检索词。
2. **时间路由和受控补读**：宿主明确选择current/history，或由有界规划器提出读取计划；历史页面用before游标续读。as-of业务时间查询需要新的生效时间模型，不能把数据库插入时间当事实生效时间。
3. **真实历史到候选的自动提取**：输出来源ID、原文片段偏移/哈希、subject/predicate/value、expected_version；确定性校验片段，再走现有待审和owner批准。单列抽取准确率、冲突、人工批准耗时、索引成本；目前脚本seed不能代表这些能力。
4. **外部有效性与上线条件**：在许可允许的LoCoMo/LongMemEval固定样本和独立真实业务样本上比较强基线；保持gold隔离。接真实身份认证、持久session、请求限流、模型调用预算/遥测、故障恢复后再谈生产服务。当前公开演示账号不能直接上线。

这些是具体后续范围，并非已完成项目。本轮交付及逐题证据以[实际报告](DEEPSEEK_RESULTS.md)为准。
