## 接口与兼容

`GET /api/projects/:p/sources?q=标题关键词&limit=25&after=0`返回 `{role,sources,next_after}`，来源含id/title/content。按ID升序，after排除该编号及更小编号；默认25条，允许1–100条，after整数0–2147483647。关键词只匹配标题，使用大小写不敏感字面量子串，截取前150个UTF-16代码单元；不搜索正文。多取一行判定后续游标，末页null。无匹配返回空数组。重复/非法参数400，未登录401，跨项目非成员403。每页重新执行角色/RLS检查并使用独立只读快照。

原 `/data` 缺省与include_sources=true保留原字段和全部来源；include_sources=false跳过来源SQL并省略sources字段。四个include_*均为false时只读角色与最近100条审计；页面另行读取事实、历史、候选和来源第一页。没有迁移或删除旧来源，也没有改变候选及修订的复合来源外键。

## 使用流程与选择保持

来源列表提供上一页/下一页、按标题查找、刷新来源及每条“选作依据”。依据下拉框仅显示本页最多25条及一个跨页保留的已选来源，最多26项。首次有来源时默认选择第一条；之后翻页、检索、空结果、读取失败或整页刷新均不悄悄更换依据，界面明确显示已选ID和标题。项目切换清除原项目选择；未取得有效选择时禁用提议按钮。

用户可以从当前页下拉框或“选作依据”显式更换选择。新来源创建成功后选中新ID，并明确提示“已保存并选为依据”；即使当前检索不匹配，新来源也作为已选项保留。服务端提交候选时仍校验来源存在且属于当前项目，不信任浏览器保存的选项。

长正文先显示120字符预览，可展开完整正文；短正文直接显示。长无空格正文、标题及已选来源提示可换行；浏览器另用合法长度的146字符长标题验证移动视口无横向溢出。关键词有label，分页状态礼貌播报，键盘翻页后聚焦来源标题；旧响应不会覆盖新检索。模拟场景按标题单独查询来源，避免依赖当前页是否包含初始示例。

来源应用接口只支持新增，无修改/删除接口，应用角色无UPDATE权限。分页不改变已有来源内容或引用；并发新增高ID可以出现在后页。多页并非共同快照，晚提交事务仍可能改变可见集合，因此不适合作严格时间点导出。行数有界不保证固定SQL扫描量；数据库管理员绕过应用长度约束后也不保证绝对字节上限。
