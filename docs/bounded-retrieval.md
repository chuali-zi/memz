# 当前事实的游标分页

新增 `GET /api/projects/:p/facts?q=关键词&limit=50&after=0`，复用登录、项目成员权限、RLS 和单次只读 REPEATABLE READ 事务。返回 `{role,facts,next_after}`；事实字段与原 `/data` 的 `facts` 相同，只包含当前修订，按事实 ID 递增。没有写操作或数据库迁移。

`limit` 默认 50、范围 1–100；`after` 默认 0、范围 0–2147483647，表示排除该 ID 及以前的事实。两者只接受单个十进制整数字符串。关键词只接受单个字符串，截取前 200 个 UTF-16 代码单元，保持原字面量子串匹配。参数错误返回 400，未登录 401，非成员 403。查询多取一行判断后续页；`next_after=null` 表示结束，否则下次传回该值。改变项目或关键词必须重置游标。

原 `/data` 响应结构和页面行为保持不变。需要同时展示来源、候选、历史的页面仍使用原聚合快照；新接口供只需要当前事实的调用方显式采用。

## 实际测量

2026-11-04 在云端 PostgreSQL 16.15、Node 24.19 的随机临时库运行固定合成用例。以下是未压缩 UTF-8 JSON 字节数，不是 SQL 执行时间、压缩流量或并发容量结论。旧接口与新接口返回的信息范围不同。

| 合成填充事实 | 查询 | 原聚合响应字节 | 新接口第一页字节 | 新接口全遍历字节 / 页数 |
|---|---|---:|---:|---:|
| 200 | 无匹配 | 100753 | 45 | 45 / 1 |
| 2000 | 无匹配 | 865363 | 45 | 45 / 1 |
| 200 | 空关键词 | 129115 | 6826 | 28578 / 5 |
| 2000 | 空关键词 | 1145932 | 6826 | 282354 / 41 |

每页限制 50。两档各 19 个用例均验证原接口和分页完整遍历的结果；空关键词项目内分别返回 206、2006 条事实。原响应即使无匹配仍返回所有来源、候选与修订历史，因此规模随历史增长。原始本次报告在工作区 `artifacts/retrieval-scale-200-after.json` 与 `artifacts/retrieval-scale-2000-after.json`，记录代码 SHA-256 和工作区状态；CI 默认规模报告随 retrieval-evaluation artifact 保存，不能将不同运行的字节数或耗时混用。

复现：设置测试管理员 `EVALUATION_DATABASE_URL` 后运行 `npm run eval:retrieval`；增加 `EVALUATION_FILLER_COUNT=2000` 可复现大档。默认 200，可设置整数 200–5000，避免无意无限扩张测试。

## 验收与边界

`test/pagination.js` 的五组数据库测试由 `npm run test:migrations` 在随机临时库执行：完整遍历无重复、当前版本与字面量搜索、成员隔离、边界参数、翻页间插入更高 ID。迁移套件现共九组；旧 HTTP 集成、幂等并发测试继续运行。

单页有一致快照，多页之间没有共同快照：新建更高 ID 可能出现在后页，已翻过 ID 的值或匹配状态变化可能漏过，不能用于严格时间点导出。游标只是位置，不是授权凭证，每页重新核验成员资格。限制行数不等于固定字节上限，也不限制数据库为寻找匹配项所扫描的行数。尚未对原聚合接口、来源、候选、历史或页面分页；它们的规模风险仍在，后续需设计独立列表加载与一致性提示。没有据此新增索引或声称查询性能优越。
